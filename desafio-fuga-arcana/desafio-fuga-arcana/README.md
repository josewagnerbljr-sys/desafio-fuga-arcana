# Mosteiro Condenado: Fuga Arcana (Desafio DIO)

Bem-vindo ao repositório do projeto **Fuga Arcana**, desenvolvido como requisito para o desafio "Criando seu Primeiro Jogo: Clone do Flappy Bird" da Trilha de Unity da Digital Innovation One (DIO).

## 🎮 Sobre o Projeto
Este projeto consiste em um clone das mecânicas clássicas do *Flappy Bird*, mas adaptado para o universo *dark fantasy* do "Mosteiro Condenado". Em vez de um pássaro, controlamos a Essência Arcana do Irmão Elian. O objetivo é consolidar conceitos de Física 2D, Endless Runner e detecção de colisões.

## 🕹️ Como Jogar
- **Pular/Flutuar:** Pressione `Espaço` ou clique com o `Botão Esquerdo do Mouse`.
- **Objetivo:** Passe entre as pilastras sem tocar nelas ou nos limites da tela.

## 🧠 Estrutura do Código
- `JogadorController.cs`: Gerencia o *input* e a física do jogador.
- `MoverObstaculo.cs`: Faz os obstáculos rolarem lateralmente e os destrói ao sair da tela.
- `GameManager.cs`: Controla o *spawn* procedural de obstáculos e o placar.
